# Divyanshu Parmar — Next.js + MUI Portfolio

## Requirements
- Node.js 20.9+ (Node 22 LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Production build
```bash
npm run build
npm start
```

## Notes
- Built with Next.js App Router, React, Material UI, Framer Motion and responsive CSS.
- The three project dashboard previews are built as editable React components (not flattened screenshots).
- Add your real resume PDF at `public/resume.pdf` to enable the resume buttons.
- Update LinkedIn/GitHub profile URLs in `components/Navbar.jsx`.
- Update project URLs and descriptions in `app/page.jsx`.
- AWS Amplify is described as basic familiarity, as requested.
- If you use a different Node version, switch to Node 20 or 22 LTS before installing.
